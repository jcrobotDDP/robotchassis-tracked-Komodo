## 🖼️ Product Pictures

The `Product pictures` folder contains all product images. These images are referenced in the user manuals and can be used for documentation, marketing, and support purposes.

**How to upload images:**
1. Navigate to the `Product pictures` folder
2. Upload your product images (JPG, PNG formats recommended)
3. Update the image references in the relevant user manual documents
